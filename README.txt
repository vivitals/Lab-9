STRIKE A CHORD — LESSONS 1–8 PROJECT PACKAGE
============================================

Included:
- index.html, lessons.html, instructors.html, rentals.html, contact.html, template.html
- css/styles.css
- scripts/script.js
- media/piano-practice.wav
- media/guitar-practice.wav
- media/violin-practice.wav
- media/bass-practice.wav

HOW TO USE
1. Download and extract the ZIP.
2. Open the extracted strike_a_chord_lesson8 folder.
3. Double-click index.html to preview in your browser.
4. Keep css, scripts, and media folders alongside the HTML files.
5. If you already have a course music folder, back it up first, then copy these files into it.
6. Open lessons.html and test each audio player.

AUDIO
The four WAV clips are original synthesized note patterns made for this project. They are included in the ZIP and should play locally in modern browsers. They are not the original audio from the reference website.

SCOPE
This is an original sample implementation through the requested pre-Lesson-9 stage. It includes audio players as practice examples, but does not add video or a Lesson 9 audio/video assignment section.

IMPORTANT FOR CLASS
Compare the included files with your textbook/course directions before submitting. If your instructor provided specific audio files or exact required code comments, use those course materials where required. The contact form is a front-end demonstration and does not send messages to a server.
